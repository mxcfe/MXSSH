# MXSSH

使用 FastAPI、AsyncSSH 和 xterm.js 的浏览器 SSH 终端。

## 启动

安装 [uv](https://docs.astral.sh/uv/) 后，在项目目录运行：

```bash
uv run main.py
```

浏览器访问 `http://127.0.0.1:8000`，在连接管理中保存 SSH 主机、端口、用户名和密码，然后打开终端或文件。网页通过 jsDelivr 加载 xterm.js，浏览器需要能访问该 CDN。

## 连接管理

在“连接管理”中可以新增、查看、编辑和删除 SSH 连接。点击“终端”或“文件”会分别新建只显示终端或文件的会话标签；标签内仍可打开另一面板。编辑时密码留空会保留原密码。连接信息保存在项目目录的 `connections.sqlite3` 中，数据库会自动创建并已加入 `.gitignore`。密码以明文保存在该文件中，请限制文件访问权限，不要分享或提交数据库。

新增或编辑连接时可以测试账号密码；保存前也会测试，失败时可选择继续保存。编辑时测试如果未填写新密码，会使用已保存的密码。首次遇到未信任的 SSH 主机密钥或密钥变化时，页面会显示 SHA256 指纹；请通过可信渠道核对后再选择信任。确认的密钥按主机和端口保存在 `connections.sqlite3` 中，连接时仍会验证服务器实际出示的密钥。

SSH 连接和测试的单次连接超时时间为 10 秒，包含 TCP 建连、握手和认证；等待用户确认主机密钥的时间单独计算。

顶部固定显示“连接管理”首页；每次发起 SSH 连接都会新建一个会话标签。点击标签切换会话，切换页面不会断开已有会话。
右上角可切换深色和浅色主题，选择保存在当前浏览器中，并应用到所有终端会话。

可以连续建立多个 SSH 连接，通过顶部标签切换会话；每个会话保持独立。点击“断开”或标签上的“×”会结束对应 SSH 会话。刷新页面或在同一浏览器配置、同一网站地址下打开新标签页时，会尝试恢复共享会话；所有页面断开后超过 60 秒未恢复，服务端自动关闭该 SSH 连接。多个标签页可以同时操作同一个远程终端，终端尺寸由最近一次调整的页面决定；在任何页面手动断开会关闭所有页面的该会话。服务重启、远端断开或浏览器本地存储被清除时无法恢复。恢复时最多回放最近 1 MiB 终端输出。

终端工具栏中的“全屏”按钮可以放大终端，再次点击或按 Esc 退出全屏；全屏时仍可切换会话。

连接列表支持按名称、主机、用户名和端口搜索。终端页面提供字号调整和本地清屏。焦点不在输入框或终端时，可使用 `Alt+1`、`Alt+2` 分别切换到连接管理和终端；在终端中不会截获这些按键。

终端工具栏的“按键”按钮可展开或收起屏幕按键栏，方便手机发送 Esc、Tab、方向键及常用 Ctrl 组合等按键。

在连接管理中点击“文件”，或在会话中打开文件面板，即可通过 SFTP 浏览远程目录、输入路径、上传和下载文件。上传支持选择多个文件，目标目录中已有同名文件时不会覆盖；连接断开后传输不可继续，失败的上传会尝试清理未完成文件。下载在浏览器内存中暂存后保存，大文件需要足够的浏览器内存。目标服务器需要启用 SFTP 并授予相应目录权限。

终端工具栏的“终端”和“文件”按钮可以分别开关面板，至少保留其中一个；同时打开时分屏显示。切换 SSH 标签会保留各会话的面板状态和文件浏览位置。打开文件面板时尝试跳转到终端当前目录；从仅文件视图重新打开终端时，会尝试向终端发送 `cd` 命令进入文件面板当前目录。若无法确认 shell 在前台等待输入、检测到未提交输入或目录检测不可用，则不会发送命令，并显示提示；命令执行结果以终端显示为准。
打开文件面板或点击“终端目录”时，程序会通过独立 SSH 命令通道读取 Linux `/proc`，尝试定位当前 shell 目录，无需修改服务器配置或远程文件。此功能需要服务器提供 `python3`、`SSH_CONNECTION` 和可读取的进程信息；若检测不到唯一的 shell，会提示原因并保留原目录，或者使用 shell 已报告的 OSC 7 目录。嵌套 SSH、容器、tmux 和切换用户等场景可能无法准确识别。

## 配置

编辑 `config.toml`：

- `server.host` 和 `server.port`：网页服务监听地址及端口；修改后重新启动。
- `ssh.verify_host_key`：默认 `true`，使用运行程序的用户的 SSH `known_hosts` 和页面确认的密钥校验服务器。仅在可信环境中才考虑设置为 `false`；禁用时不会显示主机密钥确认。

网页上的 SSH 端口与配置文件中的网页服务端口相互独立。目前仅支持账号密码认证，不使用本地密钥或 SSH agent。

服务默认仅监听本机，没有独立的网页登录鉴权。不要直接暴露到公网；若需远程访问，应在可信网络中使用带身份验证和 HTTPS 的反向代理。连接信息通过 WebSocket 传输，非本机访问时应使用 HTTPS/WSS。
